# toburo — редизайн сайта · превью

Дизайн-превью нового сайта рекламного агентства toburo / тобюро (ребрендинг TOTEM BURO, totemburo.ru).

Открыть: **https://evg-zhr.github.io/toburo-design/**

## Что внутри

| Раздел | Страницы |
| --- | --- |
| Концепция | moodboard, три концепции сигнатурной сцены (A — Центр внимания, B — Сеть звёзд, C — Кинетический вордмарк) |
| Система | палитра «Тёплый медиа» (основная) и отклонённая альтернатива, две шрифтовые пары, UI-kit |
| Motion | лоадер + hero, услуги с hover-видео, переход в кейс, многошаговый бриф — интерактивные |
| Макеты | главная 1440 / 390, шаблон кейса 1440 / 390 |
| Контент | ТЗ на контент кейсов и список материалов от заказчика |

Значения в квадратных скобках (`[N]`, `[КЛИЕНТ]`, `[ЛОГО]`) — места под реальные данные агентства.

## Как устроено

Исходники — артборды дизайн-холста в `source/*.dc.html`. Статичные страницы в `docs/` собираются скриптом:

```bash
python3 tools/build.py source docs
```

Прототипы — это демонстрация движения на чистом JS и CSS, не продакшн-код. В продакшне сцены собираются на WebGL (OGL / Three.js) + GSAP ScrollTrigger + Lenis.

Шрифты: Unbounded, Onest, Roboto Flex, Golos Text, JetBrains Mono — SIL Open Font License, подключены через Google Fonts.
