# toburo — редизайн сайта · превью

Дизайн-превью нового сайта рекламного агентства toburo / тобюро (ребрендинг TOTEM BURO, totemburo.ru).

Открыть: **https://evg-zhr.github.io/toburo-design/**

## Что внутри

| Раздел | Страницы |
| --- | --- |
| Ренессанс | moodboard v2 «Боттега XXI века», три направления логотипа и их анимации; выбран B — печатная марка с девизом In oculis omnium |
| Концепция | moodboard v1, три концепции сигнатурной сцены (A — Центр внимания, B — Сеть звёзд, C — Кинетический вордмарк) |

| Motion | лоадер + hero, услуги с hover-видео, переход в кейс, многошаговый бриф — интерактивные |
| Макеты | главная и шаблон кейса — живые прототипы (home.html, case.html) + мобильные макеты 390 |
| Контент | ТЗ на контент кейсов и список материалов от заказчика |

Значения в квадратных скобках (`[N]`, `[КЛИЕНТ]`, `[ЛОГО]`) — места под реальные данные агентства.

## Как устроено

Исходники — артборды дизайн-холста в `source/*.dc.html`. Статичные страницы в `docs/` собираются скриптом:

```bash
python3 tools/build.py source docs
```

Движение — демонстрация на чистом JS и CSS (`tools/live/*.js` поверх статичных макетов), не продакшн-код. В продакшне сцены собираются на WebGL (OGL / Three.js) + GSAP ScrollTrigger + Lenis.

Шрифты: заголовки — TT Travels Next (TypeType, лицензия заказчика). Файлы шрифта в репозитории **не хранятся** и не встраиваются: страницы используют установленный у зрителя TT Travels Next, иначе — замену Unbounded. Вордмарк toburo — растровые PNG из TT Travels Next, что лицензия допускает. Onest, Unbounded, JetBrains Mono — SIL Open Font License, через Google Fonts.
